# Bioacoustic VAMP Plugin Pack for Audacity and Sonic Visualiser

## Highlights

- Integration with Audacity and Sonic Visualiser
- Automatic label generation with species or sound-event names and confidence scores
- Optional geographic and seasonal filtering for BirdNET
- Support for full recordings or selected audio regions

## Integrated Models

- BirdNET v2.4
- Perch v2.0
- SurfPerch v1.0
- YAMNet v1.0

## Requirements

- Ubuntu latest
- `uv`, used to run the Python inference scripts and manage their dependencies

Install `uv` with:

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
export PATH="$HOME/.local/bin:$PATH"
uv --version
```

## Installation
- Create a vamp folder in your home directory (`$HOME`).
- Download `bioacoustic-vamp-pack-linux_x86_64.zip` from this release.
- Unzip the file.
- Copy all extracted files into `~/vamp`.
- Install `uv` if it is not already installed. It is used to create and run the Python virtual environment.
- Download and run either the Audacity AppImage or the Sonic Visualiser AppImage.

## Terminal Commands
Assuming `bioacoustic-vamp-pack-linux_x86_64.zip` is in your `Downloads` folder:
```bash
mkdir -p ~/vamp
unzip ~/Downloads/bioacoustic-vamp-pack-linux_x86_64.zip -d ~/vamp
```

### Running with Audacity AppImage
Assuming the Audacity AppImage is in your `Downloads` folder:
```bash
rm -f ~/.config/audacity/pluginregistry.cfg
chmod +x ~/Downloads/Audacity-3.7.7-x86_64.AppImage
VAMP_PATH=$HOME/vamp ~/Downloads/Audacity-3.7.7-x86_64.AppImage
```

### Running with Sonic Visualiser AppImage
```bash
chmod +x ~/Downloads/SonicVisualiser-5.2.1-x86_64.AppImage
VAMP_PATH=$HOME/vamp ~/Downloads/SonicVisualiser-5.2.1-x86_64.AppImage
```
